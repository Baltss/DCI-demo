# DCI Demo

Demo de frontend del **Sistema de Gestión de Casos DCI**, para la Dirección de Comercio Interior — Defensa del Consumidor (Provincia de Tucumán).

Es una demo de **solo frontend**: React (cargado por CDN) en un único archivo HTML, con datos de ejemplo persistidos en el `localStorage` del navegador. No hay backend ni base de datos real todavía.

## Contenido

- Panel de inicio, bandeja de casos con filtros, alta de Expedientes / Extra Expedientes / Endeudamiento, ficha de caso con historial, pantalla de prioridad de Endeudamiento y estadísticas.

## Correr localmente

```bash
npm install
npm start
```

Sirve la demo en `http://localhost:3000`.
